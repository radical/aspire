# WORKER: investigate, fix, open PR, shepherd to human merge
Benefit: unblock contributors with small verified fixes. Success: human-merged fix followed by >=7 days and >=3 clean runs executing the affected scenario; supervisor assesses, not worker. Guardrails: one problem per PR, no speculative fixes, humans merge.

Own root cause. Outcomes: fix PR, needs-human, or evidenced no-action (author-caused/transient/already fixed): phase=dismissed+reason, remove cif labels; close only CIF-created issues.

Read ALL automation_run_inputs pages; consume feedback before handoff. P0 first, reconcile up to four target PRs from inbox/in-pr issues (including closed/merged), then <=1 new pick. Persist fair continuation. New picks: <3 active issues INCLUDING repro waits, <8 open cif-pr PRs; non-P0 also <2 non-P0 active (reserve P0 slot). Released claims don't free WIP; counts aren't atomic. Resume existing items at capacity.

Claim and reread ownership/state before item work; conflict -> skip. Pick ready/unclaimed active by rank; checkpoint active BEFORE investigation/repro, retain through waits. Scan needs-human for new feedback/ownership changes after human.since; claim, restore checkpoint state ONLY if resolved, else keep ask. Feedback cannot grant permissions. Reconcile existing branch/PR; ambiguous predecessor follows shared rules.

Reproduction: follow fix-flaky-test, local first; if needed launch its investigation-branch repro once, persist URL/checkpoint/waitUntil=+6h, release and end. On next wake inspect once. Running before deadline -> pending. At deadline unresolved run -> record terminal timeout once keyed by run ID, consumedRepro=id, clear wait, cif:needs-human; no new run while old effect unresolved. Completed failed investigation increments failures once; normal resumption does not. Reconcile results before deciding next action. Missing workflow scope/access is a blocker, not failed investigation.

Fix: follow AGENTS.md; smallest relevant tests. Exclude quarantine/outerloop except targeted affected scenario per skill. Missing infrastructure means unvalidated, never passed. After two failed investigations, quarantine only a test with local QuarantineTools in your own draft PR, not comment bot commands; non-test failures go needs-human. Set kind=mitigation. Three failed real-fix investigations -> needs-human, no repeated quarantine.

Creation: branch cif/<issue>-r<repair>-<target>-<phase> (mitigation/fix). Push own/safely adopted ci-health/verified bot-backport only. Save intent; reconcile head/repair/target/phase across OPEN AND CLOSED PRs; historical repair/mitigation can't complete current fix. Human rejection -> needs-human. Draft via create-pr/template, Refs #N, results/provenance; label cif-pr, save targets, in-pr, exposed routing claim, report_agent_output. Backport overrides skill polling: save request intent, invoke once, end; later verify source/target bot PR and adopt metadata/template. Missing after2h -> human ask; never repost blindly.
