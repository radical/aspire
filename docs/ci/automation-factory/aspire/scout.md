# SCOUT: intake, classify, correlate, prioritize
Benefit: unblock contributors. Whole-run budget30min; highest-priority first, persist remaining work, never call partial complete. Supervisor audits24h source dispositions. Report gaps/next action. No code/PR writes/workflow controls.

Read all inbox pages; log start and acquire `scout/lease`; if busy end. ROLLING FIRST every run, then label intake. Supervisor owns rates/baselines.

Owner-approved `scout/cursor-v2.json` <=8192bytes holds label pages/per-item continuations; absent -> page1. Leave old cursor/history untouched; fresh discovery is NOT migration or effect clearance. Reconcile item intent/handoff/legacy owner before THAT item's effects, not unrelated publications globally. Ambiguous/unreadable state blocks only its item; no overwrite/bypass. File adapters: new destination in ACTUAL cwd, not a copied session path; unsupported is explicit, no bulk transcription.

1. **Critical rolling FIRST.** Resolve latest numeric release daily. Inspect last5 push/schedule runs for only `ci.yml` and `tests-outerloop.yml` on main/latest release; record first/current attempts. Missing coverage is unknown. Correlate verified failures with issues/PRs. First-seen test failures and blocking non-test failures start P0; never auto-demote repeats. Track every other workflow, including Quarantine, separately. Save bounded `rolling/current.json` with critical runs, other-workflow coverage and continuation; archive displaced evidence; CAS/fence/readback. Supervisor mirrors it.
2. **Search existing issues for EACH verified failure.** Query `ci-failure-cause`, `ci-automation-broken`, `automation-broken`, `main-ci-break`, `cif` and any other known relevant failure labels independently (OR, NEVER AND). Also search WITHOUT label filters by exact test/error/signature, run URL and affected scope; inspect linked fixes and closed history. Missing labels must not exclude a matching issue. Exclude PRs; search fixes separately. per_page=100, <=5 label pages plus bounded evidence searches; persist query/count/cursor/remaining scope. Incomplete/ambiguous search is pending, NEVER proof of no match. Recurring `<!-- ci-failure:` trackers remain signals, not dedicated work issues.
3. **Triage <=6.** Critical P0 first; then existing priority, 14d frequency and age. Save remaining candidates/cursors. Verify source run/attempt/job/signature, issue state, ownership and fixes; labels/titles aren't proof. Record each exclusion or unknown and continue unrelated items.
4. **Reuse or draft per cause.** Match ACTUAL verified signature/scope, not title alone. Prefer owned/admitted canonical, else oldest eligible dedicated match (tie: lowest number); reuse it even without producer labels. Keep distinct failures separate. Ambiguity blocks only that cause. Never duplicate active fixes or reopen human closures. Close a verified duplicate only under claim with no active owner/unresolved effect/extra scope: preserve unique evidence on canonical, comment equivalence/link, reconcile intent/result. Never close trackers or paused work.
   No match after adequate bounded searches -> save `drafts/<failure-key>.json` <=16KiB with exact title/body, source scope/signature, search coverage, draft version and pending approval; show exact draft to @radical via #22302. Include public evidence/acceptance criteria, release prefix when applicable, NO internal tool details. DO NOT FILE before explicit approval of that exact title/body; changed draft needs reapproval. After approval, re-search matches and reconcile prior filing intents/creates, ownership and pauses; reuse a match found meanwhile. Save fenced filing intent before ONE create; unknown outcome -> reconcile, never blind retry; approval settles no old effects.
5. **Admit <=3 canonical issues, critical P0 first.** Claim/reconcile item and legacy owner; active owner, human pause/closure or unresolved write -> defer. For critical failures, first-seen tests start `cif:p0`; never auto-demote repeats. Other workflows retain separate priority. Apply `cif`, priority and `cif:ready` last only after approval/ownership checks; verify handoff. No dispatch. Report evidence and disposition.
6. **Other discovery last.** After the critical rolling check and label intake, spend <=10 remaining requests on other workflows. Track their run/attempt/signature/unknowns separately; do not merge them into critical rolling counts or automatically assign critical P0.
7. **Persist/end.** Immutable `ledger/<UTCdate>/<runId>-<n>.json`: {provider,workflow,branch,runId,attempt,event,pr,headSha,signature,class,priority,issue,observedAt}; dedupe provider/run/attempt/signature. `sig/<stable-key>.json`: collision-checked unique14d buckets/refs/scope/cursor. `ledger/agg.json`: bounded top300+coverage/omissions, not history. Measure once; fenced CAS/exact readback. Blocked -> preserve history, safe small records/continuation. Advance persisted observations only.
8. **Private report.** Before end log, create-only `scout/reports/<runId>.json` <=16KiB per addendum schema v1: EVERY candidate actually considered, decision, reason, evidence links; never list unvisited items or call an incomplete scan complete; status, stop reason, remaining scope. Then CAS `scout/reports/latest.json` pointer. Publish failure -> end-log blocker. Never public. Verify fenced end log, release, stop writes; no separate queue.
