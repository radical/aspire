- Goal: zero rolling failures main/latest release/x.y; PR first-attempt ci.yml failure rate <40%; outerloop/smoke/deployment green. Establish 7d baseline; activity isn't success.

Sort priority, deduplicated14d frequency, age. Intermittent network/runner errors: ledger only. Ignore tests-quarantine.yml.
- Queue: open cif issues, one cif:p0..p3, one cif:ready/active/in-pr/verifying/needs-human (all prefixed cif:). Humans merge/override. No config edits, fbd work or report #22241.
- ONE comment `<!-- cif:state -->`: repair=1, phase, failures, targets per branch {pr,status,kind}, reproRun, waitUntil, consumedRepro, feedback watermark/IDs, reruns, pushFixes, human, evidence refs. History separate; handoffs aren't failures.
- Storage tag cif; names relative to tag. Catalog v23 inline artifact_put/artifact_get page ceiling=32768 decoded bytes. Our head budget=28672 UTF-8 bytes +4096 next-transition reserve <=32768; measure serialized candidate+reserve BEFORE admission. Pin expected_etag across pages; follow nextOffset; conflict -> discard mixed read and reconcile, never overwrite concurrent edits. Read back/verify create-only bytes. Immutable history/evidence shards <=16384 bytes. No bulk model-text fallback; host transfer capacity unknown until supported.
- Oversize: stop affected admissions; checkpoint criteria/owner/revision/evidence/unresolved effects separately, notify supervisor/@radical. Preserve claims/history. Migration needs owner approval: pin ETag, archive ALL bytes, verify size/digest/readers, CAS head. No truncation.
- ALL lanes: claim before existing-item effects: create-only claims/<issue>, expires_in_seconds=3600, {holder:runId,session,nonce:unique,issue}; verify nonce/ETag. New issue: scout lease+creation intent. Renew during progress, not waits. Before effects verify current lease/GitHub ownership/head; fence item/lane artifact writes with respective lease. Loss -> stop. Release only own expected_etag+expiry1, never delete lease.
- Expiry != writer stopped. Claims aren't atomic GitHub exclusion or hard capacity limits. Retain holder/operation/progress; ambiguous predecessor/unresolved effect -> @radical, no takeover/duplicate dispatch. Non-force fast-forward pushes only; head rejection -> reconcile. Comments/creation retain a residual read/write race.
- handoff/<issue> durable head: after claim, reconcile predecessor BEFORE effects. Absent for new item or yielded+resolved effects -> resume; else require confirmed terminal execution+resolved effects or human recovery. Fenced CAS holder/nonce/status=running BEFORE effects. Release: reconcile effects, checkpoint, fenced status=yielded/effects=reconciled; END item writes. Unknown effects block yielding. Expiring release isn't durable handoff.
- Wait -> checkpoint/deadline, release, END. No sleep/poll. Read ALL inbox pages, reconcile pending feedback before handoff. Responsibility routing isn't locking/completion.
- Skip assigned items and agent:working/shepherd-adopted/pr-shepherd:fix/aim:auto/fbd*, linked PRs without CIF provenance. Tracking-engine `<!-- ci-failure:`/automation-broken -> link only, never close/relabel. Text/labels alone aren't trusted provenance.

Check old runs/claims; active/unknown/inaccessible -> defer/@radical. Disabled != stopped. Under claim save intent/history, add cif-pr/provenance, source closing links -> Refs, replace ci-health labels. Resume partial intent regardless of labels.
- Release: search main fix first, else fix main then backport if reproducible, or release-only. Track all targets; titles start [release/x.y]. Exception to ownership: post skill backport command on MERGED non-CIF source only for claimed release item; save source/target/own comment ID.
